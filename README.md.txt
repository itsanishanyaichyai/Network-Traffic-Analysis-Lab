# Network Traffic Analysis Lab

## Project Overview
This project demonstrates basic network traffic analysis using Wireshark and a sample packet capture. The investigation focuses on DNS queries and responses to understand how domain-name resolution appears in network traffic.

## Tools Used
- Wireshark
- Sample DNS packet capture (`dns.cap`)
- Windows

## Investigation Tasks
- Applied DNS display filters in Wireshark.
- Identified a DNS query for `google.com`.
- Located a corresponding DNS response.
- Recorded source and destination IP addresses.
- Documented findings and captured screenshots.

## Key Findings
- DNS traffic for `google.com` was observed in the sample capture.
- A DNS response associated with the query was identified.
- The returned IP address was not recorded during this review.
- The available evidence did not confirm malicious activity.

## Project Structure
- `01_Sample_Traffic` — Sample packet capture.
- `02_Analysis` — DNS query and response notes.
- `03_Investigation_Reports` — Investigation summary.
- `04_Screenshots` — Wireshark screenshots.

## Conclusion
This lab provided hands-on practice with Wireshark display filters, DNS packet inspection, basic network investigation, and security documentation. Further analysis of packet details and surrounding traffic would be required to investigate potential threats.

**Note:** This project uses sample traffic for educational purposes. Observing a domain or DNS response alone does not establish malicious activity.
